# Smart-File-Organiser

A desktop utility for file organization, duplicate detection, and file integrity verification built using C.

## Overview

Smart-File-Organiser is a modular command-line tool designed to help you manage cluttered directories. It provides automated sorting, accurate duplicate identification using cryptographic hashing, and a manifest-based integrity checker to ensure your files remain unaltered over time.

## Features

* File Organization: Automatically sorts messy directories by moving files into dedicated subfolders based on their file extensions.
* Duplicate Detection: Identifies exact duplicate files using a two-step process (file size comparison followed by precise SHA-256 hash comparison) to safely free up storage space.
* Integrity Verification: Creates and verifies file manifests to track changes and guarantee data integrity.

## Project Structure


## Testing Environment

To safely demonstrate and test the utility, a `test_folder` is included. This folder contains 14 dummy files across various formats (documents, images, spreadsheets, etc.), including intentionally duplicated files. 

Note: The dummy test environment and its files were generated using the AI application Gemini (model name: Gemini 3.1 Pro - Advanced Reasoning) specifically to validate the sorting and duplicate detection scripts.

## How to Build and Run

This project includes an automated batch script for Windows users to compile and launch the application seamlessly.

1. Ensure you have a C compiler (like GCC via MSYS2/MinGW) installed and added to your system PATH.
2. Open your command prompt or terminal.
3. Navigate to the root directory of the Smart-File-Organiser project.
4. Execute the deployment script:
   ```cmd
   build_and_run.bat
   ```
5. The script will automatically compile the source code in the `src` folder, output the `SmartFileTool.exe` executable into the `build` directory, and launch the main menu.
